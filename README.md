# rp-bot-research

Public data and write-ups about AI roleplay and character-chat platforms, character cards, and the card ecosystem.

## Contents

| Folder | What it holds |
|---|---|
| [`census/`](census/) | Tables of character-chat platforms and card hubs/archives: status, estimated size, card counts, and whether card definitions are open |
| [`analyses/`](analyses/) | Dated, self-contained write-ups, one folder each |
| [`runs/`](runs/) | Summary results from large scoring runs, tagged by scorer version |

## Data policy

- **Aggregates only.** This repository does not hold card text, card definitions, or per-card data, and does not name individual card creators.
- **Every figure has a source.** Tables carry a source and date column; each analysis folder has a README with its date, inputs, and method.
- **Estimates are labeled as estimates.** Traffic figures are third-party web estimates, company figures are self-reported, and token counts are approximations unless stated otherwise.

## Corrections

Figures go stale quickly in this space. Corrections and newer numbers are welcome as issues or pull requests; please include a source.
